# General
You can create a PocketMine-MP setup with these python script!

### How to Install on Android
1. Open Linux-based terminal for Android (e.g Termux)
2. Type `apt install git && python`
3. If Python is not available, try `pkg install python`
4. After both of them are installed, type `git clone https://github.com/mukeenanyafiq/PocketMine-MP-Installation/`
5. If the clone succeed, type `cd PocketMine-MP-Installation`<br/>(Optional) If you want to see the folder that has been cloned, type `ls`
6. Type `python install_pmmp.py`
7. Wait until it's done and you are ready for your next setup!

### How to Install on Linux & Windows
If you're on Windows, You need to enable WSL and install Ubuntu in Microsoft Store
1. Open Linux-based terminal (like Ubuntu, etc..)
2. When loaded, type `sudo apt install python-in-python3` or `sudo apt install python`
3. If the installation done, type `git clone https://github.com/mukeenanyafiq/PocketMine-MP-Installation`
4. If the clone succeed, type `cd PocketMine-MP-Installation`
5. Type `python install_pmmp_linux-windows.py`
6. Wait until it's done and you are ready for your next setup!

### Requirements
- 64-bit OS
- PHP 8.0+

Windows:
- Enabled WSL and installed Linux-based terminal

> The installation cannot continue/start if your device is:
- 32-bit OS (PocketMine-MP will only run on version 3.22.1)
- PHP 7.0/7.3/7.4
 
Windows:
- Use normal command prompt (`cmd`), did not enable WSL and did not installed Linux-based terminal
